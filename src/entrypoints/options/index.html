Pretty PR Review

Features

Languages

Each language is described by a language file (JSON with comments): its tokens, where functions and classes are, and what counts as formatting. All features use it. Python is built in; download its file as a template (every key is explained inside), edit it, and upload it. A file with the id of a built-in language replaces it. Changes apply right away; reload open PR tabs. 


      


      

        
Colors

        
Each feature has its own color. The fade sets how far formatting-only lines fade from red/green toward the page background. Changes apply to open PR tabs as soon as you save.

        

      


      

        
Auto-viewed file patterns

        
Test files and markdown by default.

        

          One glob per line. Evaluated in order, last match wins; prefix with ! to exclude.
          Patterns without a / match the file name.
